Self-hosted for editorial headings, with Arial used for reading and application controls.

The `source-serif-4-latin-*` files are subsets of these originals made with FontTools 4.60.2 for common English, Portuguese, and Spanish glyphs, punctuation, and symbols. Both weight and optical-size variation axes are retained. Their internal family and PostScript names use RWAS Editorial to respect the original Reserved Font Name; original copyright, trademark, attribution, and OFL metadata remain intact. The CSS family is an alias used by the existing typography policy. The shared stylesheet selects subsets with `unicode-range`; the complete upstream files remain available for all other glyphs. The license above also covers the subsets. See the [OFL FAQ on modified font names](https://openfontlicense.org/ofl-faq/).
