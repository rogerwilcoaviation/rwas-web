# RWAS comprehensive SEO audit and remediation

Audit date: October 23, 2026, America/New_York. Some evidence timestamps are October 24 UTC.

Site: https://www.rogerwilcoaviation.com

Scope: the complete public sitemap, internal link graph, search landing pages, metadata, canonicalization, internationalization, headings, images, structured data, crawl controls, performance, mobile accessibility, local citations, and AI discovery information. Private account actions and commercial transactions were not exercised.

## Assessment

The website has a sound technical foundation. All 1,898 sitemap URLs returned HTTP 200, every page had a unique title and description and one H1, and the crawl found no broken internal links, orphan sitemap pages, missing social metadata, accidental noindex directives, or invalid JSON-LD. All six URLs sampled through Google's URL Inspection API were submitted and indexed.

The repeat audit found new defects introduced since the previous review: language landing canonicals pointing to redirecting URLs, a lazy-loaded homepage LCP image, unnecessarily large font downloads, inaccessible contrast in the inventory empty state, missing image dimensions in recent content, missing service-specific structured data on new service pages, outdated AI-discovery copy, and stale schema expectations in the catalog audit. The source fixes and local production build are complete; final production verification is recorded below when the release completes.

Lighthouse's SEO category scored 100/100 on all six baseline page types. This is a sampled technical score, not a site-wide ranking or business-performance score.

## Findings and implemented fixes

### 1. Language canonicals and alternate URLs

Both `/es` and `/pt-br` returned HTTP 200, while `/es/` and `/pt-br/` redirected with HTTP 308. Their canonical and homepage hreflang links pointed to the redirecting forms. Google's URL Inspection independently showed Google selecting the slashless URL while the declared canonical retained the slash.

The two landing-page canonicals, reciprocal homepage language alternates, language picker links, and Portuguese breadcrumb reference now use the slashless URLs that match the sitemap. Localized contact and Papa-Alpha alternate groups already referenced the correct distinct pages. Each page remains self-canonical with reciprocal English, Portuguese, Spanish, and x-default links. Reference: [Google's localized-page guidance](https://developers.google.com/search/docs/specialty/international/localized-versions).

### 2. Homepage rendering and font transfer

The homepage AXIS image was the mobile Largest Contentful Paint element. It had `fetchpriority="high"` but inherited `loading="lazy"` from the shared image component. It now explicitly loads eagerly while retaining its dimensions and priority.

The recently introduced Source Serif 4 files transferred 429,100 bytes for Roman and 346,688 bytes for italic. Latin subsets now transfer 196,312 and 166,748 bytes respectively: reductions of 54.2% and 51.9%. Weight and optical-size variation axes remain intact. Disjoint Unicode ranges serve common English, Portuguese, and Spanish characters from the smaller files; the complete original fonts remain available for other characters. The typography browser suite passed 98 views with the approved family and layout policy.

### 3. Inventory empty-state contrast

The homepage's no-inventory message used `#888` on a cream background, which Lighthouse measured at 3.08:1. It now uses the existing dark `--ink-600` token. Loading and unavailable-inventory messages share the corrected styling.

### 4. Image dimensions and content maintenance

The newly published flight-log article omitted dimensions on its 3200×910 hero and 858×292 provider-logo image. The manual dimensions map had not been updated when those assets were added. A build-time generator now reads actual local article images and generates the map on every `appinfo` run, covering both article hero/lightbox and Markdown imagery. This prevents the same defect recurring with future locally hosted article images.

Added dimensions to the About lightbox, collection product frames, and standalone Garmin masthead; the Garmin masthead also uses the existing optimized WebP logo. Existing Next Image `fill` images already reserve layout through fixed/aspect-ratio containers and were distinguished from images lacking reserved layout.

### 5. New service metadata and structured data

The three printing/coating pages previously inherited only the site Organization and WebSite graph. They now include page-specific Service, WebPage, and BreadcrumbList nodes, referencing the existing RWAS organization identity. The child services include their real parent breadcrumb. Titles and descriptions now identify Yankton and describe the actual offered work and review process.

No review scores, product availability, prices, or regulatory approvals were fabricated. Papa-Alpha's existing Brand/ItemList graph and the pre-buy facility-referral page retain their appropriate distinct semantics.

### 6. Catalog audit false positives

All 503 emitted Product nodes in the live crawl contained genuine structurally qualifying offers. The full catalog script nevertheless reported 805 missing Product nodes because its historical quote-only list no longer covered the current render policy.

Product pages now expose the result of the same eligibility function that controls schema emission. The audit reads that current policy and retains its historical fallback for older pages. Missing or malformed markers still require schema for newly encountered products, preventing silent suppression of real errors. Three regression cases cover current-policy precedence, malformed/missing policy, and HTML attribute quoting, and run in deployment CI.

The complete built catalog classifies as:

| Classification                                     | Count |
| -------------------------------------------------- | ----: |
| Product schema present                             |   503 |
| Intentionally omitted under current snippet policy | 1,324 |
| Unexpectedly missing                               |     0 |
| Render-policy / schema disagreement                |     0 |

This correction changes audit accuracy; it does not convert quote-only listings into online offers.

### 7. AI discovery accuracy

`llms.txt` still advertised pre-buy inspections as an RWAS service even though the actual service page now explicitly offers independent facility recommendations. It also contained old fixed Papa-Alpha starting prices.

The file now accurately describes the referral service, directs readers to live product pages for prices, and includes the new printing/coating pages and localized Papa-Alpha guides. Current shop identity, address, telephone, and airport remain consistent with the website's canonical location page.
